<objective>
Implement the UpstreamConnectionManager that owns per-session upstream MCP Client instances with lazy connection, concurrent-safe getOrConnect, and session-scoped cleanup. Wire the manager into the existing session destruction lifecycle so upstream connections are closed when sessions expire or are explicitly terminated.

Purpose: This is the core component of Phase 1 - it manages the lifecycle of upstream MCP connections per downstream session. Lazy initialization (PROXY-01) ensures no upstream resources are consumed until actually needed. The closeAll method integrates with the existing session reaper (REL-02) to prevent connection leaks. The wiring into http-transport.ts destroySession path guarantees zero upstream connection leaks on session expiry.

Output: UpstreamConnectionManager class with full test coverage for lazy connect, concurrency dedup, closeAll, and session destruction integration wired into http-transport.ts.
</objective>
