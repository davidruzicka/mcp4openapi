## Known Issues

**Zod error quality for profile-file path:** When a user has `upstream_mcp: [{...}]` in their profile JSON/YAML, the Zod parse error is a raw JSON-serialized ZodError (code: `invalid_type`, expected: `object`, received: `array`). This is less user-friendly than the env-var path which shows the clear migration message "must contain a single JSON object, not an array. Change [{...}] to {...}". Consider wrapping the loader's `enhancedProfileSchema.parse(json)` in a try/catch in a future phase to unify error quality.
