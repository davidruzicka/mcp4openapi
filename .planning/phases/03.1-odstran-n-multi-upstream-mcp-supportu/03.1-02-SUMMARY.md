### hasUpstreamMcpFlag (new export in upstream-mcp-config.ts)

```typescript
export function hasUpstreamMcpFlag(value: unknown): boolean {
  if (Array.isArray(value)) {
    return value.length > 0;
  }
  return value !== null && typeof value === 'object';
}
```

Rationale (Open Question 1 resolution): profile-resolver.ts and generic-profile.test.ts both read the raw profile JSON value BEFORE Zod validation, so they see both legacy array shape and new singular object shape during the migration period. A shared helper centralizes the dual-shape detection and documents the migration intent with a MIGRATION-CLEANUP comment.
