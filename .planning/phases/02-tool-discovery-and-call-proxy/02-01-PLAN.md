  <action>
    Create `src/upstream/upstream-notification-queue.ts` per D-08:

    1. Export interface:
       ```typescript
       export interface NotificationQueueEntry {
         method: string;
         timestamp: number;
         params?: unknown;
       }

       export interface NotificationQueueOptions {
         maxSize?: number;
         ttlMs?: number;
       }
       ```

    2. Export class `NotificationQueue`:
       - Private `entries: NotificationQueueEntry[] = []`
       - Private `readonly maxSize: number` (default 50)
       - Private `readonly ttlMs: number` (default 300_000 = 5 min)
       - Constructor accepts optional `NotificationQueueOptions`
       - `push(entry: NotificationQueueEntry): void`:
         a. IMPORTANT (addresses review concern): Evict expired entries using `Date.now()`, NOT `entry.timestamp`:
            ```typescript
            const now = Date.now();
            this.entries = this.entries.filter(e => (now - e.timestamp) < this.ttlMs);
            ```
            Using `Date.now()` is correct because it measures real wall-clock age. Using `entry.timestamp`
            would produce incorrect results under clock skew or when the incoming entry has a non-current timestamp.
         b. If `this.entries.length >= this.maxSize`, shift oldest: `this.entries.shift()`
         c. Push new entry
       - `drain(): NotificationQueueEntry[]`:
         a. `const result = [...this.entries]`
         b. `this.entries = []`
         c. Return result
       - `get size(): number` returns `this.entries.length`

    Create `src/upstream/upstream-notification-queue.test.ts` with tests for all behaviors. Use vitest. Use `vi.useFakeTimers()` for TTL tests.

    IMPORTANT (addresses review concern): TTL test must verify that eviction uses wall-clock time (Date.now), not the incoming entry's timestamp. Test pattern:
    ```typescript
    it('evicts entries based on wall-clock time, not incoming entry timestamp', () => {
      vi.useFakeTimers();
      const queue = new NotificationQueue({ ttlMs: 1000 });
      queue.push({ method: 'test', timestamp: Date.now() });
      vi.advanceTimersByTime(1500); // 1.5s later
      queue.push({ method: 'test2', timestamp: Date.now() });
      expect(queue.size).toBe(1); // first entry evicted by TTL
      vi.useRealTimers();
    });
    ```
