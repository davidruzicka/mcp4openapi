    Create `src/upstream/upstream-notification-queue.ts` per D-08:

    1. Export interface:
       ```typescript
       export interface NotificationQueueEntry {
         method: string;
         timestamp: number;
         params?: unknown;
       }

       export interface NotificationQueueOptions {
         maxSize?: number;
         ttlMs?: number;
       }
       ```

    2. Export class `NotificationQueue`:
       - Private `entries: NotificationQueueEntry[] = []`
       - Private `readonly maxSize: number` (default 50)
       - Private `readonly ttlMs: number` (default 300_000 = 5 min)
       - Constructor accepts optional `NotificationQueueOptions`
       - `push(entry: NotificationQueueEntry): void`:
         a. Evict expired: `this.entries = this.entries.filter(e => (entry.timestamp - e.timestamp) < this.ttlMs)`
         b. If `this.entries.length >= this.maxSize`, shift oldest: `this.entries.shift()`
         c. Push new entry
       - `drain(): NotificationQueueEntry[]`:
         a. `const result = [...this.entries]`
         b. `this.entries = []`
         c. Return result
       - `get size(): number` returns `this.entries.length`
