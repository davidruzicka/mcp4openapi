<objective>
Extend the existing Prometheus metrics infrastructure with per-upstream and per-client-identity labels (OBS-02), and add structured audit logging for every tools/call invocation (OBS-01).

Purpose: Operators need per-upstream and per-identity observability for gateway tool calls. Security teams need an audit trail per call with identity and outcome.

Output:
- `MetricsContextLabels` extended with `upstreamHost` and `clientIdentity`
- `resolveContextLabels` returns all four label keys; `client_identity` capped at 64 chars
- Counter/Histogram `labelNames` for `mcpToolCallsTotal`, `mcpToolCallDuration`, `mcpToolCallErrors` updated
- New `getSessionClientPrincipal` accessor on HttpTransport
- `resolveMetricsContext` in mcp-server.ts populates `clientIdentity` from session
- All `recordToolCall`/`recordToolCallError` call sites in HTTP and stdio paths enriched with `upstreamHost`
- `logger.info('audit:tool_call', {...})` emitted at every success and error outcome (both paths)
- Tests for new labels in metrics.test.ts and audit log assertions in mcp-server.test.ts
</objective>
