## 2026-08-11 - [Path Traversal in URL interpolation] **Vulnerability:** Unencoded dot characters in URL path segments lead to path traversal vulnerabilities. **Learning:** `encodeURIComponent()` does not encode `.` by default, allowing malicious users to supply path parameters like `../` to manipulate backend API endpoints. **Prevention:** Always sanitize interpolated URL paths by calling `.replace(/\./g, '%2E')` after standard URI component encoding.
